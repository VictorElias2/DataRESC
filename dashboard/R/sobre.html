Este dashboard foi desenvolvido por Victor Elias com o objetivo de demonstrar os principais problemas nos dados do Diagnóstico da Conectividade na Educação, cujo link poderá ser acessado clicando aqui.

Na seção início, a análise é feita com valores concretos e corretos, sendo filtradas para demonstração de como são os dados e apresentação dos dados nos quais é analizado.

Na seção de auditoria, a análise já é feita com todos os valores nos dados. Incluindo os erros que aparecem e algumas demonstrações deles, indicando algumas falhas indiretamente ou não da apresentação destes dados, demonstrando erros quantitativos e de lógica que a fonte apresenta.

O objetivo deste sistema é indicar à disciplina de Auditoria de Sistemas, que nas tecnologias de coleta de dados utilizadas para a fundação Nic.BR não estão adequadas para uma análise adequada destes dados, tanto como uma transparência dos mesmos.
